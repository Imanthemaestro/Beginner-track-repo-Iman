# Beginner Track Structure

This folder follows the required structure for the Beginner Track submission.

## Folder Breakdown

- projects/  
  Contains completed beginner-level project(s).

- prompts/  
  Contains a record of prompts used during development, with explanations of how they helped.

- documentation/  
  Contains learning notes, challenges faced, and reflections on the development process.

All code is written clearly and committed regularly with meaningful messages.
